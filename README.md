# Alireza — Architecture Portfolio

Portfolio of coursework by Alireza, architectural engineering student at Islamic Azad University, Karaj.

- `/` — main portfolio
- `/atelier/` — alternative clean layout
- `/sheets/` — A3 landscape sheets for the PDF version

## Adding a new work

1. Put the images in `img/`.
2. Open `index.html` (and the other layouts if you use them) and find the `WORKS` list near the bottom.
3. Copy the existing entry, change the title, course, year, medium, text and image paths.
